## 💡 The Idea

Hospitals, schools, and institutions generate massive amounts of operational data — but struggle to translate it into **green compliance, safety readiness, and actionable intelligence**.

**GreenSafe AI** sits on top of existing data and converts it into:
- 📊 Automated KPI scoring against IGBC / NBC / CPCB benchmarks
- 🔍 AI-powered gap analysis with root cause and ROI
- 🎯 Prioritised action plans with evidence requirements
- 🤖 Conversational AI for compliance queries

---

## 🏗️ Platform Architecture

```
Building Data Input
        ↓
Compliance Knowledge Graph
(IGBC Green Healthcare · NBC 2016 · CPCB · DPCC · BEE)
        ↓
AI Rule Engine → KPI Scoring Engine
        ↓
Gap Analysis AI → Recommendation Engine
        ↓
Risk + Priority + Cost/ROI
        ↓
GreenSafe Readiness Score → Action Plan → Evidence Tracker
```

## 🏥 Demo Hospital

**City Medical Centre, Delhi**
- 350 beds · Multi-specialty · Built 2008
- **Current GreenSafe Score: 59/100**
- **Target after action plan: 92/100 (IGBC 4-Star)**
- **Total investment: ₹91 lakh → ₹30.3L/yr saving → ROI: 36 months**

### Critical Issues Found:
1. 🚨 4 emergency exits obstructed (NBC 4.2 violation)
2. 🔴 OPD CO₂ at 1,480 ppm (ASHRAE limit: 1,000 ppm)
3. 💧 Water quality certificate expired Dec 2023
4. 🌬️ Cafeteria PM2.5 at 55 μg/m³ (WHO limit: 25)

## 🚀 Quick Start

### Run Locally
```bash
git clone https://github.com/YOUR_USERNAME/greencare-demo.git
cd greencare-demo
# Just open in browser:
open index.html          # Mac
start index.html         # Windows
```

### Enable Full AI (Optional)
In the **GreenSafe AI** tab, enter your Anthropic API key:
```
KEY:sk-ant-api03-...
```
Without key: smart fallback responses based on hospital data are used.
